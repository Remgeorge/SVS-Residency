# SVS-Residency
Society Application

## Live Website
The site is published with GitHub Pages and can be viewed at:

https://remgeorge.github.io/SVS-Residency/

## Local Preview
To run the site locally:

1. Open a terminal in the repository root.
2. Run `python3 -m http.server 8000`.
3. Visit `http://127.0.0.1:8000` in your browser.
